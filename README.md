# SchoolTrack
  School Track é um software que visa mapear rotas de transportes públicos escolares na cidade de Jacobina, promovendo assim, avanços tecnológicos , transparência de dados e acessibilidade aos discentes e à região.
  O software implementará linguagens de programação (HTML, PHP, JavaScript e CSS), banco de dados (SQL) e georreferenciamento, que opere tanto em web quanto em mobile, com uma identidade visual simples, dinâmica e de fácil acesso, assim promovendo acessibilidade e usabilidade aos usuários. 
  O programa terá recursos como login, cadastro, perfil de usuário, tela inicial com as opções de visualizações de rotas contendo horários, rotas, mapa, informações sobre a empresa, aba de esclarecimento de dúvidas, além de um  sistema de notificações ao usuário em tempo real.
